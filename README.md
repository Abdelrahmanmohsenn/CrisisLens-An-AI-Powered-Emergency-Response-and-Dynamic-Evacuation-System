# CrisisLens-An-AI-Powered-Emergency-Response-and-Dynamic-Evacuation-System
CrisisLens is an AI-powered emergency response system that analyzes incident reports and images, retrieves relevant safety knowledge using RAG, assesses hazard severity, and dynamically recommends safer evacuation routes using graph-based optimization. Built with Mistral, BLIP, FAISS, LangChain, NetworkX, and Streamlit.
